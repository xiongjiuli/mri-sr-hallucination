# AI 使用记录（AI Usage Record）

本记录对应课程要求“保留主要 AI 使用记录，并说明 AI 完成了什么、成员作出了哪些判断”。
按课程说明，本项目属于“AI 辅助科研”任务，允许并鼓励使用大模型辅助检索、编程、调试、实验和写作；
所有 AI 产出均需由小组成员核验后才能作为最终成果提交。

## 1. 使用的工具与模型

| 用途 | 工具 | 说明 |
|---|---|---|
| 代码编写、实验执行、结果整理、论文初稿 | DeepSeek Harness（deepseek-flash） | 2026-11-05 会话，工作目录为本项目根目录 |
| 文献检索与核对 | 人工 + 通用检索 | 论文引用均为公开可查的原始论文，提交前需再次核对卷期页码 |
| 写作润色 | 由本组负责“AI 辅助写作”的成员使用本组 Skill | 与本记录分开提交 |

## 2. AI 完成的工作

1. **文献框架**：给出 MRI 超分辨率、幻觉评估、不确定性门控三部分的代表性文献列表，并起草 related work。
2. **代码实现**：实现 `src/` 下的数据预处理、退化算子、RRDB、DSC 损失、感知损失、误差头、门控、向双三次收缩、COP、评价指标和绘图脚本。
3. **数据与实验**：下载公开 IXI T1w 数据，调用 deepbet 完成脑提取，生成按受试者划分的数据集，训练像素损失、感知损失、MKDA、DSC+MKDA 等模型并运行评价。
4. **结果整理**：从 `results/*.json|csv` 自动生成论文中的数字宏（`src/make_numbers.py`），保证论文数字与实验记录一致。
5. **论文与报告初稿**：撰写英文论文结构、方法、实验、结果和讨论初稿，以及中文项目报告初稿。

## 3. 小组成员必须核验的内容（人工判断）

提交前至少完成以下检查，并在报告中记录“谁检查了什么”：

- [ ] **数据划分**：`data/processed/splits.json` 中训练/验证/测试受试者无交集；测试集只在最终评价时使用。
- [ ] **预处理**：随机抽取 5 个受试者，确认脑提取、1 mm 重采样、256×256 切片和归一化没有明显错误（可用 `results/figures/fig_qual.png` 与切片图）。
- [ ] **指标实现**：逐行核对 PSNR、SSIM、HFEN、FER、COP 的定义是否与论文公式一致；用“相同图像”与“加噪图像”做 sanity check。
- [ ] **训练配置**：确认 4 个模型的 backbone、参数量、迭代数、学习率、损失权重一致；确认 best checkpoint 只按验证集 PSNR 选择。
- [ ] **关键数字**：随机抽取论文表 I/II/III 中的 6 个数字，与 `results/summary_*.json`、`results/cop_*.json` 对照。
- [ ] **统计检验**：确认 Wilcoxon 检验的零假设、配对方式和样本量（按切片配对）无误。
- [ ] **引用**：逐条核对 `paper/refs.bib` 的作者、年份、卷期页码；删除无法核实的条目。
- [ ] **结论措辞**：确认摘要与结论中的因果表述不超过实验证据。本项目的核心是一个“负结果 + 简单改进”：感知/MKDA 增加幻觉、DSC 未降低、收缩有效；不要把收缩包装成新网络。
- [ ] **AI 声明**：在论文致谢/报告和汇报中如实说明 AI 参与范围。

## 4. 已知局限与需要人工补做的工作

- 没有放射科医生参与的读者研究；COP 是自动替代指标，不能完全代替专家判断。
- 只评估了健康成人 T1w、2D 轴向切片和合成退化；真实低分辨率 MRI 的层厚、运动、线圈不均匀性未建模。
- 论文的英文表达需要由小组统一润色，并通过本组写作 Skill 检查符号、公式、图表和引用一致性。
- 汇报 PPT 与录屏、写作 Skill 的评测由其他成员完成，本记录不覆盖。

## 5. 结论
